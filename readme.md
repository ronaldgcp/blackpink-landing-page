# 🎤 BLACKPINK Landing Page

A music landing page created as a Platzi project with AI assistance, inspired by BLACKPINK. The goal was to build a striking, interactive, and modern visual experience to promote a fictional festival or concert with K-pop style.

## 📖 Project Description

This project is a landing page built with Next.js, React, and TypeScript. It's designed to present a complete music event experience, with visual sections, user interaction, and dynamic elements like a cart, simulated authentication, tickets, merch, galleries, and animations.

The main goal was to practice using AI tools to speed up the design and implementation of an attractive interface, while keeping a clear and easily extendable structure.

## 🛠️ Technologies Used

## 🚀 How to Run the Project

### Prerequisites

- Node.js 18 or higher
- pnpm installed

### Installation

```bash
pnpm install
```

### Development Mode

```bash
pnpm dev
```

Then open the app in your browser at the address shown in the terminal, usually:

```bash
http://localhost:3000
```

### Production Build

```bash
pnpm build
```

### Run in Production Mode

```bash
pnpm start
```
